# Class Inventory

| Class ID | Class Name | Purpose/Responsibility | Related Use Case(s) | Contributor |
|---|---|---|---|---|
| C01 | User | Abstract generalization of all system users. Holds the shared account data (name, email, hashed password, role, failed-login count, lock status, locked-until time). Handles registration, authentication, logout, password changes and resets, and the 15-minute lockout after 5 failed logins (NFR16). | UC-01, UC-06, UC-15, UC-16, UC-19 | Zainab |
| C02 | Applicant | A person applying for a driving test. Extends User with applicant-specific data: unique ID number, address, phone, and overall record status (LICENSED / RETEST_REQUIRED, FR15). Requests, cancels and reschedules bookings, views results, requests certificates, and edits profile fields (FR23). Its record status is updated after each result. | UC-06, UC-16 | Zainab |
| C03 | Administrator | A user who manages bookings and examiner assignments. Extends User with admin-specific data (staff ID, department). Assigns and reassigns examiners and views all bookings. Booking filtering and details are provided by BookingManager. | UC-01, UC-15, UC-05, UC-09, UC-18, UC-20 | Zainab, Areej |
| C04 | Examiner | A user who conducts tests. Extends User with examiner-specific data (examiner number, license categories certified for). Submits availability, views their schedule of assigned tests, and submits test results. | UC-01, UC-14, UC-15, UC-17 | Zainab, Areej |
| C05 | PasswordResetToken | A single-use, time-limited token emailed to a user for password reset. Tracks expiry and whether it has been used, so a reset link can't be reused or kept valid indefinitely. | UC-15 | Zainab |
| C06 | Session | Represents an authenticated login. Holds the session token, creation and expiry times, and active status, and returns the logged-in user. Invalidated on logout (FR25). | UC-01, UC-19 | Zainab |
| C07 | AuditLog | Keeps a permanent, read-only record of important actions so any change can be traced to who did it and when. Each entry stores the user, the action type (e.g. booking created, booking cancelled, profile updated, result submitted, notification failed), the affected record, and a timestamp. Supports NFR17. Entries can be created but never edited or deleted. | UC-16, UC-03, UC-12, UC-07 | Zainab |
| C08 | TestSlot | Represents a driving test appointment, including its date, start and end time, location, and booked status. Ensures a slot can only be reserved once and can be released after cancellation or rescheduling. | UC-02, UC-03, UC-04, UC-12 | Farah |
| C09 | Booking | A driving test reservation made by an applicant. Stores the unique booking reference, booking status, test type, creation date, cancellation date, and its test slot. Supports retrieving booking details and tracking its lifecycle: confirmation, cancellation, rescheduling, and completion. | UC-03, UC-04, UC-11, UC-12, UC-13 | Farah |
| C10 | BookingManager | Manages booking operations: searching for available slots, validating the 30-minute booking cutoff, checking for conflicting reservations, generating reference numbers, creating bookings, processing cancellations and rescheduling, and providing filtered booking lists and booking details for administrators. | UC-02, UC-03, UC-04, UC-05, UC-11, UC-12 | Farah |
| C11 | Availability | One block of time (date, start, end) an examiner declares they are available to work. Checks whether it covers a test slot or overlaps with another time block. | UC-05, UC-17, UC-20 | Areej |
| C12 | ExaminerAssignment | Links one examiner to a booking, with the assigning admin, time, and status (ACTIVE or REVOKED). Keeping it separate preserves assignment history. | UC-05, UC-14, UC-17 | Areej |
| C13 | ScheduleManager | Controller for Process 4.0. Records and removes availability, checks examiner availability, lists the examiners available for a slot, prevents double assignment, creates and reassigns assignments, logs audit entries, triggers notifications, and builds examiner schedules. | UC-05, UC-14, UC-17, UC-18, UC-20 | Areej |
| C14 | Notification | A message sent to a user about an event, with type, text, time sent, and read status. Covers all six notification types: examiner assigned, assignment revoked, result available, and booking confirmed, cancelled, and rescheduled. | UC-03, UC-04, UC-05, UC-07, UC-08, UC-12 | Areej |
| C15 | NotificationService | Creates and sends notifications for booking, examiner assignment, and result events, and lists a user's notifications. Retries a failed notification up to 3 times, then logs the failure and alerts the administrator (FR27). | UC-03, UC-04, UC-05, UC-07, UC-08, UC-12 | Areej, Aira |
| C16 | AssignmentStatus (enum) | ACTIVE, REVOKED | UC-05, UC-14 | Areej |
| C17 | NotificationType (enum) | EXAMINER_ASSIGNED, ASSIGNMENT_REVOKED, RESULT_AVAILABLE, BOOKING_CONFIRMED, BOOKING_CANCELLED, BOOKING_RESCHEDULED | UC-08 | Areej, Aira |
| C18 | TestResult | Driving test outcome: pass or fail, score, remarks, the examiner who submitted the result, and submission time. Each booking has at most one result. This is the D5 Results record. | UC-07, UC-10, UC-13 | Aira |
| C19 | Certificate | Document issued to applicants who passed. Has a unique certificate number, issue date, and a link to the result that earned it. Can only exist for PASS results. | UC-10 | Aira |
| C20 | ResultManager | Controller for Process 5.0. Checks examiner assignment and that the test time has passed, records one result per booking, marks the booking completed, updates the applicant's record status, returns applicants' own results and test history, issues certificates for PASS results, writes audit entries, and triggers result notifications. | UC-07, UC-08, UC-10, UC-13 | Aira |
| C21 | Role (enum) | APPLICANT, ADMINISTRATOR, EXAMINER. Determines role-based redirection and access (FR06). | UC-01 | Zainab |
| C22 | RecordStatus (enum) | LICENSED, RETEST_REQUIRED. An applicant's overall record status, updated after each result (FR15). | UC-07, UC-13 | Zainab |
| C23 | ActionType (enum) | ACCOUNT_REGISTERED, PROFILE_UPDATED, BOOKING_CREATED, BOOKING_CANCELLED, BOOKING_RESCHEDULED, AVAILABILITY_SUBMITTED, AVAILABILITY_REMOVED, EXAMINER_ASSIGNED, EXAMINER_REASSIGNED, RESULT_SUBMITTED, CERTIFICATE_ISSUED, NOTIFICATION_FAILED | UC-03, UC-07, UC-12, UC-16 | Zainab |
| C24 | BookingStatus (enum) | CONFIRMED, CANCELLED, RESCHEDULED, COMPLETED | UC-03, UC-04, UC-11, UC-12, UC-13 | Farah, Areej |
| C25 | Outcome (enum) | PASS, FAIL | UC-07, UC-10, UC-13 | Zainab, Aira |
