# Scenarios

| **Scenario ID** | **Scenario Name** | **Primary Actor** | **Scenario Description** |
|-----------------|-------------------|-------------------|--------------------------|
| **S-01** | Applicant Booking a Driving Test | Applicant | A new applicant registers using their full name, verified email address, and password, then logs into the system and searches for available test slots in their area. The applicant selects a slot for Monday at 12:00 pm. Before confirming the booking, the system checks that the slot is still available, that there are no booking conflicts, and that the test is at least 30 minutes away. If all conditions are satisfied, the system reserves the slot, creates the booking, generates a unique booking reference number, and sends the applicant a confirmation message. |
| **S-02** | Managing an Upcoming Booking | Applicant | An applicant realizes they have other commitments on Friday, the day a previous driving test was booked; they navigate to "My Bookings," delete the initial booking, and select a new available slot. The booking system releases the original slot back into the pool and sends a confirmation for the new booking, notifying the applicant of the change. The applicant may also cancel the booking without selecting a new slot, in which case the original slot is released and a cancellation confirmation is sent. |
| **S-03** | Examiner Submitting a Pass/Fail Result | Examiner | After conducting a driver's test, the examiner logs into the system and accesses their dashboard. The examiner selects the test from their list of assigned tests and submits either a "Pass" or "Fail" result alongside optional notes. The system records the date and time of submission, updates the applicant record, and marks the booking as completed. The applicant receives a notification that their result is available. If the applicant passes, a result certificate becomes available for download. |
| **S-04** | Administrator Assigning an Examiner a Test Slot | Administrator | An administrator accesses the admin dashboard and views the upcoming bookings, which can be filtered by date, location, or examiner-assignment status. The administrator opens a booking to view its details and identifies that it has no assigned examiner. They view the examiners available for the selected date and time and assign one. The booking record is updated, and the examiner is notified. |
| **S-05** | System Preventing a Double Booking | Applicant and System | Two applicants both try to book a slot at 9:00 am. The system applies an automatic database-level lock, allowing the first applicant to book and immediately marking it unavailable. The other applicant receives an error message, followed by a prompt to select another time. |
| **S-06** | Resetting a Forgotten Password | Applicant, Examiner, Administrator | A registered user cannot remember their password and selects "Forgot Password" from the login page. The system sends a password-reset link to the user's verified email address. The user sets a new password and can access the account again. |
| **S-07** | Updating Profile Information | Applicant | A logged-in applicant opens their profile and changes editable personal information, such as their address or phone number. The system saves the updated information to the applicant's profile. |
| **S-08** | Setting Examiner Availability | Examiner | An examiner logs into the system and enters the days and times during which they are available to conduct driving tests. The system stores this availability so that administrators can consider it when assigning examiners to bookings. |
| **S-09** | Logging Out | Applicant, Examiner, Administrator | A logged-in user selects "Log Out." The system ends the active session and prevents access to protected functions until the user logs in again. |
