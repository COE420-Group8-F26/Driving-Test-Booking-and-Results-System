# Project Description

The Driving Test Booking and Results System is designed to organize and centralize the process of scheduling driving tests and managing their results for the applicants, the driving examiners, and the administrators.

Applicants can register, view available test slots, manage their bookings, and access their results. Driving examiners can view assigned tests and submit pass or fail results. Administrators manage schedules, bookings, examiner assignments, and test records.

A test booking moves through different states from booking to completion/cancellation. Once a test is completed, the examiner records whether the applicant passed or failed, and the system updates the applicant's record.

The system also sends notifications when relevant changes occur, such as a booking being rescheduled or a test result becoming available.

The main functionalities include account management, test booking and scheduling, examiner assignment, result management, notifications, and test history.
