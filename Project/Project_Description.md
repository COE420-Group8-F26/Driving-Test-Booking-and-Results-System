# Project Description

The Driving Test Booking and Results System is a software system designed to simplify the process of booking driving tests and managing test results. 
It addresses the need for a centralized and organized system that allows users to schedule tests and access their results efficiently.
The intended users are driving test applicants and driving test administrators. 
The system will allow applicants to register, view available test dates and times, book or reschedule driving tests, and view their test results. 
Administrators will be able to manage test schedules, applicant bookings, and record and update test results.

The main functionalities of the system include user registration and login, test appointment management, booking and rescheduling, test result management, and access to test history.
